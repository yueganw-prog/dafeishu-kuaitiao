# 大飞鼠快跑 🐿️

> TapTap Maker 竖屏小游戏 · 横版飞行躲避收集 · 点按扇翅 + 按住滑翔混合操控

操控一只展开翼膜的大飞鼠，在夜色森林里穿缝躲枝、收集松果。手感优先：推力缓动曲线、挤压拉伸、hit-stop 慢动作死亡演出、连收音调递升——每一帧都有反馈。

## 🎮 玩法

| 操作 | 效果 |
|---|---|
| 点按 | 扇翅冲量，瞬时抬升（响应优先） |
| 按住 | 滑翔推力缓动"咬合"，持续升力 |
| 松手 | 重力自然下落 |

- 🌰 收集松果 +10，2.5 秒内连收触发 **combo 音调递升**
- ✂️ 贴着树枝缝飞过（净距 <28px）触发**擦身 +5**
- 🌲 撞树 / 落地即败，难度随时间 smoothstep 上升，每 4 组障碍安排一个"呼吸段"

## 🎒 道具（每 9~14 秒随机出现）

| 道具 | 效果 |
|---|---|
| ❄ 寒冰护盾 | 挡一次树枝：碎枝 + 白闪 + 1.2s 无敌穿过 |
| 🔥 炫火轮 | 6s 光环，期间撞树 = 撞毁 +50 分 |
| 🌪 风域 | 3s 托举，自动平滑升力（可叠冲量） |

## ✨ 手感细节

- 撞树演出：hit-stop 冻结 0.09s → 白闪 + 大屏震（带微旋转）→ 慢动作翻滚坠落 → 世界滑停 → 结算面板
- 高速下坠挤压拉伸、扇翅压扁脉冲、残影轨迹、高速风线
- 死亡后世界不瞬间定格，而是阻尼滑停
- 结算面板 EaseOutBack 弹入 + 分数滚动上涨

## 🔧 技术

- **平台**：TapTap Maker（UrhoX 引擎）· Lua 5.4
- **渲染**：整条管线纯 NanoVG 矢量绘制——零贴图、零外部资源，全部几何拼装
- **特效**：自研轻量粒子/飘字/屏震/hit-stop 模块（`scripts/Fx.lua`），与渲染同管线
- **音频**：隐藏场景 + SoundSource 池已接线（`scripts/Audio.lua`），缺素材自动静默降级
- **竖屏**：项目声明 + 运行时双重 portrait，布局全按屏幕比例自适应

## 📁 结构

```
scripts/
├── main.lua       入口（引擎对接/事件分发，保持薄）
├── Config.lua     全部可调数值（调手感只改这里）
├── Game.lua       状态机 + 计分 + 反馈接线
├── World.lua      障碍/松果/道具生成与碰撞
├── Player.lua     混合操控物理 + 挤压拉伸 + 残影
├── Renderer.lua   全部 NanoVG 绘制
├── Fx.lua         粒子/飘字/闪光/屏震/hit-stop
├── Audio.lua      音效系统（文件契约见下）
└── Utils.lua      数学/缓动/碰撞工具
```

## 🔊 音效文件契约

把同名 WAV 放进 `assets/Sounds/` 即自动生效，缺文件静默跳过：
`flap / pickup / powerup / shield / nearmiss / fire / crash`

音量与音调抖动在 `scripts/Config.lua` 的 `Config.Audio` 调整。
